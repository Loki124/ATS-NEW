## §3 决策记录（ADR）

**ADR-001 · 轮岗资源「平台」字段对三类形态全开**

- **背景**：兵哥原话「ATS-new 项目下的轮岗资源中针对客服部门类型的资源也需要支持填写平台字段」；PRD v1.0 初稿按「`OTHER` 维持拒绝」派生出 5 条验收条目。
- **选项**：① 仅放开客服部门；② 三类形态全开（客服部门与其他选填）；③ 维持仅直播间可用。
- **决定**：**②**（闸口1 人确认，2026-10-23）—— 平台字段按**形态无关**处理；字典复用 `LIVE_ROOM_PLATFORM`、展示名中性化为「轮岗平台」；存量不回填、零迁移。决策行 **D-14**。
- **影响**：后端去掉按形态的 400 分支；Excel 导入改「仅直播间必填判空」；前端平台下拉取消按形态禁用 / 清空 / 置 null；产品层验收表 **A-03 / A-07 / A-13 / A-15 / A-34 作废**、**A-35～A-40 生效**。
- **回滚点**：commit `99d7dfa6`（单 commit 可回退）；**无数据迁移** ⇒ 回滚不涉及数据修复（`platform` 列已存在且模型无 CheckConstraint）。
- **正文**：`docs/03-product/校招生管理需求规格与实施方案.md` D-14；`docs/03-product/PRD_轮岗资源客服部门平台字段.md` §0 / §5.4 / §5.5。
