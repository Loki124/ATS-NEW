# T7.4 · 5 列表页操作列 n-dropdown 化（I3 / P1）
> 最后更新：2026-09-07（依据 git 最后提交）

## 1. 前置
```bash
# 5 列表页操作列现状（粗看每页 3-4 个按钮）
grep -nE "n-button|<button" web/app/src/pages/{offer,demand,onboarding,interview,candidate}/*List.vue | grep -E "详情|编辑|删除|转移|取消|推进|备注"
# 期望: 每个 List.vue 至少有 3 个操作类按钮
```

## 2. 目标
5 列表页操作列从「3-4 个横向按钮」改为「1 个 + 下拉」（详情 + 更多），压缩列宽到 ≤160px。

## 3. 具体 diff（通用模板）

**5 文件**：每个文件的操作列 template 段

```diff
- <n-button size="small" @click="handleDetail(row)">详情</n-button>
- <n-button size="small" @click="handleEdit(row)">编辑</n-button>
- <n-button size="small" @click="handleTransfer(row)">转移</n-button>
- <n-button size="small" type="error" @click="handleDelete(row)">删除</n-button>
+ <n-button size="small" @click="handleDetail(row)">详情</n-button>
+ <n-dropdown :options="actionOptions(row)" trigger="click" @select="(k) => onAction(k, row)">
+   <n-button size="small">更多 ⌄</n-button>
+ </n-dropdown>

+ <script setup> 段追加
+ function actionOptions(row) {
+   return [
+     { label: '编辑', key: 'edit' },
+     { label: '转移', key: 'transfer' },
+     { label: '删除', key: 'delete', props: { style: 'color: var(--c-error)' } },
+   ]
+ }
+ function onAction(key, row) {
+   if (key === 'edit') handleEdit(row)
+   if (key === 'transfer') handleTransfer(row)
+   if (key === 'delete') handleDelete(row)
+ }
+ </script>
```

**说明**：「详情」保留主按钮（最高频操作），其他进 dropdown。具体替换内容根据每个文件实际函数名调整。

## 6. 失败处理
- 操作列函数名不一致 → grep 实际函数名再调整
- 「更多」按钮被 n-data-table cell 高度截断 → 加 `:show-arrow="false"` 或调整 cell padding
- 探针最后列宽 > 200px → 可能详情按钮文字过长 → 改 `详情 → 查看` 短词
