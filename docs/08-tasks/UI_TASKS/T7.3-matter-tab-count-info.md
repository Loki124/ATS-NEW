## 2. 目标
Dashboard.vue matter-tab__count 当前用品牌色（不该） → 改信息色（未读/通知 = info）；新增 urgent 变体给真正紧急状态用 c-error。

## 3. 具体 diff

**文件**：`web/app/src/pages/Dashboard.vue` L646-654 + L56-66

### 3.1 L646-654 CSS 段
```diff
- .matter-tab__count {
-   background: var(--brand-soft);
-   color: var(--brand);
- }
+ /* v2: 未读/通知类计数 = info；紧急/逾期 = error（用 .matter-tab__count--urgent） */
+ .matter-tab__count {
+   background: var(--c-info-soft);
+   color: var(--c-info);
+ }
+ .matter-tab__count--urgent {
+   background: var(--c-error-soft);
+   color: var(--c-error);
+ }
```

### 3.2 L56-66 template 段（如有 urgent 用法）
```diff
- <span v-if="(data?.matterCounts?.[tab.key] ?? 0) > 0" class="matter-tab__count">
+ <span v-if="(data?.matterCounts?.[tab.key] ?? 0) > 0"
+       :class="['matter-tab__count', tab.urgent && 'matter-tab__count--urgent']">
```

**注**：如果 `tab.urgent` 不存在，**本任务仅改 CSS**；template 段不动。
