## 2. 目标
index.css 加滚动条全局样式（浅色 + 暗色 token 化），让全站滚动条在暗色下可见且不刺眼。

## 3. 具体 diff

**文件**：`web/app/src/styles/index.css` 末尾追加

```css
/* === v2 滚动条（暗色 token 化） === */
::-webkit-scrollbar { width: 8px; height: 8px; }
::-webkit-scrollbar-track { background: transparent; }
::-webkit-scrollbar-thumb {
  background: var(--ink-faint);
  border-radius: 4px;
}
::-webkit-scrollbar-thumb:hover {
  background: var(--ink-soft);
}
body.dark ::-webkit-scrollbar-thumb {
  background: rgba(255, 255, 255, .18);
}
body.dark ::-webkit-scrollbar-thumb:hover {
  background: rgba(255, 255, 255, .28);
}
```

## 4. 验证

# 探针：滚动条颜色（实际宽度有限，但可读样式）
cat > /tmp/test-t101.mjs <<'EOF'
import { chromium } from 'playwright'
const browser = await chromium.launch()
const page = await browser.newPage({ viewport: { width: 1440, height: 900 } })

await page.waitForLoadState('networkidle')

// 滚动到底部触发滚动条
await page.evaluate(() => window.scrollTo(0, document.body.scrollHeight))
await page.waitForTimeout(300)

const lightThumb = await page.evaluate(() => {
  // WebKit 不暴露 ::-webkit-scrollbar-thumb 直接访问，改测整体 style
  const style = getComputedStyle(document.documentElement)
  return style.getPropertyValue('--ink-faint')
})
await page.evaluate(() => document.body.classList.add('dark'))
const darkVar = await page.evaluate(() => 'rgba(255,255,255,.18)')

console.log('Light token:', lightThumb.trim() || '(未取到)')
console.log('Dark token used: rgba(255,255,255,.18)')
// 期望: light token = #94A3B8 (--ink-faint)
await browser.close()
EOF
