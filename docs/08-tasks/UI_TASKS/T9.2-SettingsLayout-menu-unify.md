## 2. 目标

## 3. 具体 diff

### 3.1 template 段（L15-60 附近）
```diff
- <div v-for="group in menuGroups" :key="group.key" class="menu-group">
-   <div class="menu-group__title">{{ group.title }}</div>
-   <div v-for="item in group.items" :key="item.key"
-        :class="['menu-item', { active: selectedMenu === item.key }]"
-        @click="selectedMenu = item.key; router.push(item.path)">
-     {{ item.label }}
-   </div>
- </div>
+ <n-menu :options="menuOptions" :value="selectedMenu" @update:value="handleMenuClick" />
```

### 3.2 script 段
```diff
- const menuGroups = ref([...])
- const selectedMenu = ref('xxx')
- function onMenuClick(...) { ... }
+ const menuOptions = computed(() => [
+   {
+     type: 'group', label: '外观', children: [
+       { label: '主题外观', key: '/settings/theme' },
+     ]
+   },
+   {

+   },
+   ...
+ ])
+ const selectedMenu = computed(() => route.path)

+   router.push(key)
+ }
```
