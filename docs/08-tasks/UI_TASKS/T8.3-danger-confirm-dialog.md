## 2. 目标
3 文件危险状态操作前弹 `dialog.warning()` 二次确认（用户取消则 return）。

## 3. 具体 diff（3 文件）

**通用模式**（以 OfferList handleTransitionSubmit 为例）：
```diff
+ import { useDialog } from 'naive-ui'
+ const dialog = useDialog()

  async function handleTransitionSubmit() {
    if (...) { message.warning('请填写原因'); return }
+   // v2: 危险状态二次确认
+   const dangerStates = ['REJECTED', 'WITHDRAWN', 'EXPIRED']
+   if (dangerStates.includes(transitionModal.value.form.to)) {
+     try {
+       await dialog.warning({
+         title: '确认操作',
+         content: `将 Offer 状态变更为「${OFFER_STATUS_LABEL[transitionModal.value.form.to]}」，是否继续？`,
+         positiveText: '确认',
+         negativeText: '取消',
+       })
+     } catch { return }
+   }
    transitionModal.value.loading = true
    // ...原逻辑
  }
```

**3 文件分别修改**：
- OfferList.vue：handleTransitionSubmit / handleReject（拒绝 offer）
- InterviewList.vue：handleCancel（取消面试）
- OnboardingList.vue：handleReject（拒绝入职）

**useDialog 已在 App.vue 的 `<n-dialog-provider>` 注册**——可直接 `import { useDialog } from 'naive-ui'`。
