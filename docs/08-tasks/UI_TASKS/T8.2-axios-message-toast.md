## 2. 目标
已有拦截器仅 console.warn/error（PM 看 console 不现实）→ 加 `message.warning('接口不存在: ...')` 和 `message.error('服务异常...')` 用户提示。

## 3. 具体 diff

**文件**：`web/app/src/main.ts` L21-37

```diff
+ import { createDiscreteApi } from 'naive-ui'
+ const { message } = createDiscreteApi(['message'])

  axios.interceptors.response.use(
    (resp: AxiosResponse) => resp,
    (err: AxiosError) => {
      const status = err?.response?.status
      const url = err?.config?.url ?? '<unknown>'
      if (status === 404) {
        console.warn(
          `[API 404] 后端没实现这个 endpoint: ${url}\n` +
          `  → 这是 "后端 app 缺" 不是 "权限问题". 看报告: REPORT-2026-06-29-ats-complete.md §10`
        )
+       message.warning(`接口不存在: ${url.split('?')[0]}`)
      } else if (status === 500) {
        console.error(`[API 500] 后端 bug: ${url}`, err?.response?.data)
+       message.error('服务异常，请稍后再试')
      }
      return Promise.reject(err)
    }
  )
```

**注意**：`createDiscreteApi` 必须在 axios 拦截器**之前**声明（const message），否则拦截器引用时 message 是 undefined。

## 6. 失败处理

- toast 重复弹出（同一 404 多次）→ 加 `message` 去重（Naive UI 默认 3s 自动消失；或加 url 缓存 5s 内不重复）
- 探针 no-toast → 检查 axios 是否真的发送了请求；或换 mock 端点
