# 01 - 项目概览

## 1. 项目定位

ATS-NEW 是一套**企业内招聘管理系统（Applicant Tracking System）**，覆盖招聘全生命周期：

```
招聘需求(Demand) → 职位发布(Position) → 候选人接入(Candidate/AddCandidate)
→ 申请与流程流转(Application + Process) → 面试(Interview/Invitation)
→ Offer 发放(Offer) → 入职(Onboarding) → 人才库回流(TalentPool)
```

配套支撑能力：权限体系（V1/V2 双轨）、字段级 ACL、审计日志、通知四渠道、GDPR 合规、自动化规则引擎、数据看板、内推、校招管控、MOU 大客户协议等。

## 5. 后端 app 分层总览

35 个本地 app 按职责分为 5 层：

| 分层 | app 数 | app 列表 |
|---|---|---|
| **核心支撑层** | 8 | `core`（用户/组织/权限/认证）、`field_acl`（字段级 ACL）、`audit`（审计）、`dictionary`（数据字典）、`notification`（通知）、`gdpr`（合规）、`integration`（外部集成）、`common`（公共基类/工具） |
| **流程域** | 4 | `process`（招聘流程）、`entry_condition`（进入条件）、`time_limit`（阶段限时）、`automation`（自动化规则引擎） |
| **业务域** | 17 | `candidate`、`add_candidate`、`application`、`demand`、`position`、`offer`、`onboarding`、`invitation`、`interview`、`referral`、`talent_pool`、`channel`、`analytics`、`mou`、`announcement`、`campus_control`、`resume_flow` |
| **资源库** | 1 | `library`（院校/公司库） |
| **轻量端点型** | 5 | `search`（全局搜索）、`scraped_resume`（RPA 抓取）、`duplicate_check`（查重）、`dynamic_field`（动态字段）、`external_sync`（Mock 端点） |

各 app 详情见 [03-后端模块详解](./03-后端模块详解.md)。

## 6. 关键横切能力

| 能力 | 实现 | 关键文件 |
|---|---|---|
| JWT 双 token | simplejwt，access 60min + refresh 7d + ROTATE + BLACKLIST | `apps/core/views_auth.py` |
| V2 权限 | `has_perm()` 资源码校验 + `resolve_scope()` L1-L4 数据范围 | `apps/core/permission_check.py`、`apps/core/scope_resolver.py` |
| 字段级 ACL | FieldAclService 序列化期脱敏/隐藏字段 | `apps/field_acl/services.py` |
| PII 加密 | EncryptedCharField（Fernet） | `apps/common/encryption.py` |
| 身份证查重 | `id_card_hash` 不可逆哈希 | `apps/candidate/models.py` |
| IDOR 防护 | ScopeQuerysetMixin 查询集过滤 | `apps/core/permissions_v2.py` |
| SSE 流推送 | 评分进度流式返回 | `apps/add_candidate/views.py` |
| WebSocket | `ws/notifications/` + `ws/applications/{id}/` | `apps/core/routing.py`、`apps/core/consumers.py` |
| 审计中间件 | 非 GET 写操作 + 错误响应记录（含熔断降级） | `apps/audit/middleware.py` |
| SPA fallback | 非 API 路径回退 index.html（history 路由） | `config/urls.py` `spa_fallback` |
