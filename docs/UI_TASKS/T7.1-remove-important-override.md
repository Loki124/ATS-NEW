# T7.1 · 主按钮 !important 覆盖移除（C2 / P0）

## 1. 前置
```bash
grep -rn "color: var(--ink) !important" web/app/src/
# 期望: CandidateList L859 + L1055
```

## 2. 目标
移除所有 `!important` 覆盖（与 App.vue themeOverrides 主按钮 `#fff` 冲突），改为正常优先级或专用 modifier 类。

## 3. 具体 diff

**文件**：`web/app/src/pages/candidate/CandidateList.vue` L856-860 + L1054-1055

### 3.1 L856-860 主按钮组样式
```diff
- .add-button, .batch-notify-btn, .send-btn-primary {
-   background: linear-gradient(135deg, var(--brand) 0%, var(--brand-grad-a) 100%) !important;
-   border: none !important;
-   color: var(--ink) !important;
- }
+ /* v2: 移除 !important 覆盖 · 字色由 App.vue themeOverrides (#fff) 统一控制 */
+ .add-button,
+ .batch-notify-btn,
+ .send-btn-primary {
+   background: linear-gradient(135deg, var(--brand), var(--brand-grad-a));
+   border: 1px solid rgba(255, 255, 255, .35);
+   /* 不再覆盖 color — 走全局主按钮字色 #fff */
+ }
```

### 3.2 L1054-1055 第二处
```diff
- background: linear-gradient(135deg, var(--brand) 0%, var(--brand-grad-a) 100%) !important;
- color: var(--ink) !important; font-weight: 600;
+ background: linear-gradient(135deg, var(--brand), var(--brand-grad-a));
+ /* 不再覆盖 color — 走全局主按钮字色 #fff */
+ font-weight: 600;
```
