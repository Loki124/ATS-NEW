## 2. 目标
5 列表页统一加 1280/768/480 三档响应式断点（KPI 4→2→1 折叠 + 数据表横向滚动）。

## 3. 具体 diff

**5 文件**：每个文件 `<style scoped>` 末尾追加以下 patch（**注意不要插到 `<style>` 块外**）

```css
/* === v2 响应式补丁 === */
@media (max-width: 1280px) {
  .page-container { padding: var(--space-4); }
  .page-title { font-size: var(--text-h2); }
  :deep(.n-data-table-wrapper) {
    overflow-x: auto;
    -webkit-overflow-scrolling: touch;
  }
}
@media (max-width: 768px) {
  .page-container { padding: var(--space-3); }
  .page-header { flex-direction: column; align-items: stretch; gap: var(--space-3); }
  .stats-row { grid-template-columns: repeat(2, 1fr) !important; }
}
@media (max-width: 480px) {
  .stats-row { grid-template-columns: 1fr !important; }
}
```

**操作步骤**：
1. 每个文件 Read 一下，找到 `</style>` 结束标签
2. 在 `</style>` 前用 Edit 工具插入上面 patch
3. 每个文件一个独立 commit（避免 5 文件混合 commit 难回滚）

## 6. 失败处理
- `<style scoped>` 末尾可能没有 `</style>` 紧接，可能有 `@media` 等其他规则 → 读上下文确认插入位置
- `stats-row` 在某些页可能类名不同（如 `.demand-stats`）→ 读各文件确认实际类名后调整
- 探针显示 4 列在 768 视口 → grep 自己写的 `!important` 是否被更高优先级覆盖 → 加 `:deep` 提升特异性
