## 2. 目标
5 列表页 + 设置中心所有 `n-icon-button` 加 `aria-label`（"编辑候选人"/"删除规则" 等具体动作）。

## 3. 具体 diff（典型模式）

```diff
- <n-icon-button @click="handleEdit(row)">
+ <n-icon-button aria-label="编辑候选人" @click="handleEdit(row)">
    <n-icon :component="EditIcon" />
  </n-icon-button>

- <n-icon-button @click="handleDelete(row)">
+ <n-icon-button aria-label="删除候选人" @click="handleDelete(row)">
    <n-icon :component="DeleteIcon" />
  </n-icon-button>

- <n-icon-button @click="handleMore(row)">
+ <n-icon-button aria-label="更多操作" @click="handleMore(row)">
    <n-icon :component="MoreIcon" />
  </n-icon-button>
```

**5 文件 + 设置中心**：挨个 grep `<n-icon-button` 加 aria-label。建议用 `replace_all` 但每个按钮 aria-label 不同。

```bash
# 探针
cat > /tmp/test-t102.mjs <<'EOF'
import { chromium } from 'playwright'
const browser = await chromium.launch()
const routes = ['/offer', '/demand', '/onboarding', '/interview', '/candidate', '/settings/theme']
let total = 0, withAria = 0
for (const route of routes) {
  const page = await browser.newPage({ viewport: { width: 1440, height: 900 } })
  await page.goto(`http://localhost:5212${route}`)
  await page.waitForLoadState('networkidle')
  const stats = await page.evaluate(() => {
    const btns = [...document.querySelectorAll('button[aria-label], .n-icon-button')]
    return { total: btns.length, withAria: btns.filter(b => b.getAttribute('aria-label')).length }
  })
  total += stats.total
  withAria += stats.withAria
  console.log(`${route}: ${stats.withAria}/${stats.total} have aria-label`)
  await page.close()
}
console.log(`\nTOTAL: ${withAria}/${total}`)
// 期望: 100%
await browser.close()
EOF
cd /Users/loki/WorkBuddy/招聘助手/ATS-NEW/web/app
NODE_PATH=/Users/loki/WorkBuddy/招聘助手/ATS-NEW/web/app/node_modules node /tmp/test-t102.mjs
```
