# T6.2 · Layout.vue 侧栏 ≤768 折叠为 n-drawer

## 1. 前置
```bash
# Layout.vue L40-80 是侧栏 + 顶栏搜索结构
sed -n '40,80p' web/app/src/pages/Layout.vue
# 期望看到 <n-layout-sider> + <n-layout-header> + 搜索 n-button
```

## 2. 目标
Layout.vue 侧栏在 ≤768 viewport 时折叠为抽屉（汉堡按钮触发 `n-drawer`），避免在小屏挤压主内容。

## 3. 具体 diff

**文件**：`web/app/src/pages/Layout.vue`

### 3.1 `<script setup>` 段（顶部）追加
```diff
+ const isMobile = ref(window.innerWidth < 768)
+ const mobileMenuOpen = ref(false)
+ function onDrawerMenu(key: string) {
+   router.push(key)
+   mobileMenuOpen.value = false
+ }
+ window.addEventListener('resize', () => {
+   isMobile.value = window.innerWidth < 768
+ })
```

### 3.2 `<n-layout-sider>` 改条件渲染
```diff
- <n-layout-sider v-if="menuLayout === 'side'" ...>
+ <n-layout-sider v-if="menuLayout === 'side' && !isMobile" ...>
```

### 3.3 顶栏加汉堡按钮（在 layout-header 内左侧）
```diff
+ <button
+   v-if="isMobile"
+   class="hamburger-btn glass-input"
+   aria-label="打开菜单"
+   @click="mobileMenuOpen = true"
+ >☰</button>
```

### 3.4 抽屉（放在 `<n-layout-sider>` 后）
```diff
+ <n-drawer
+   v-if="menuLayout === 'side'"
+   v-model:show="mobileMenuOpen"
+   :width="280"
+   placement="left"
+ >
+   <n-menu :options="menuOptions" :value="selectedKey" @update:value="onDrawerMenu" />
+ </n-drawer>
```

### 3.5 CSS 段追加
```diff
+ .hamburger-btn {
+   position: fixed;
+   top: var(--space-3);
+   left: var(--space-3);
+   z-index: var(--z-header);
+   width: 36px; height: 36px;
+   border-radius: var(--radius-md);
+   background: var(--glass-bg-card);
+   border: 1px solid var(--glass-border);
+   backdrop-filter: blur(var(--glass-blur-input));
+   -webkit-backdrop-filter: blur(var(--glass-blur-input));
+   cursor: pointer;
+ }
```
