重设计说明 · 问题 → 改法

P0footer 悬浮遮挡内容（截图中「范围下限/上限/步长」被按钮盖住）
flex 三段结构：header / footer 固定不参与滚动，仅 body 滚动（overflow-y:auto; overscroll-behavior:contain），内容永不落入按钮底下。落地时对应 n-modal 内层容器改造。
P0「输出单位」出现两处（表单顶部 + 参数区各一次）
合并为一处，固定放「基础信息」区；placeholder 直接提示继承值（留空则继承「年」），帮助文案说明"仅影响展示、不参与计算"。
P1分区硬编码 1/2/3，「参数配置」条件缺席时序号断裂
序号改图标：五个语义分区（基础信息 / 计算参数与范围 / 可用运算符 / 值域分段 / 备注与状态），条件分区整体隐藏，无序号错位问题。
P1出参继承信息是孤立蓝条，与「输出单位」关系费解
融合为继承摘要条：紧跟定义下拉，展示出参类型 / 继承单位 / 取值方式 + 锁形"不可修改"；单位字段的占位符与它呼应。
P1无校验反馈，点保存才知道缺什么
footer 校验摘要：待完善项以可点击胶囊列出，点击滚动定位并聚焦字段；出错字段就地红框 + 具体原因；保存成功有 toast 反馈，未保存更改在底部有黄点提示。
P1误关弹窗丢失已填内容
脏状态守卫：有未保存修改时，取消 / 关闭 / Esc 均先出「放弃修改？」确认（文案说明后果），干净状态直接关闭不打扰。
P2值域分段删除无退路、范围/分段生成结果不可见
删除支持 Toast 撤销（5 秒内可恢复）；范围与每段分段的生成档位实时预览，配置者不用心算步长序列。
P2头部无上下文，编辑态不知道自己在改哪个版本
头部元信息行：编辑态显示数据源路径 + 版本号 + 最近保存时间；新建态显示引导语。

桌面 700px 弹窗、max-height 92vh；≤640px 转全屏层，三列网格折叠为单列。切到 1/3/5 试试参数化三种定义，条件分区自动显隐。
