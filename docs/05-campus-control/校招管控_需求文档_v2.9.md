# 校招管控（人员比例管控）需求文档 v2.9
> 最后更新：2026-09-07（依据 git 最后提交）

> 版本：v2.9 ｜ 更新：2026-09-01 ｜ 状态：现行权威版（替代 2026-08-26《需求说明文档》）

## 1. 定位与目标

校招招聘过程中，按「管控规则」对**人员结构比例**与**人数配额**进行管控，在 Offer 环节实时拦截/提示，确保招聘结果符合规划。

一句话：**让校招录用在「院校 / 专业 / 性别 / 身份证籍贯」等维度上不超配额、不破比例。**

## 2. 核心术语（口径铁律）

| 术语           | 定义                                         |
| ------------ | ------------------------------------------ |
| 维度           | 管控视角，如 院校标签 / 专业标签 / 性别（可自由扩展，含身份证籍贯等动态维度） |
| 指标           | 维度下的分类值，如 985 / 工学 / 男                     |
| 规则           | 一条管控约束 = 适用范围 + 维度 + 指标 + 年度               |
| 适用范围         | 部门/职务/职级 三者，全空 = 全局                        |
| 控制强度         | 硬约束（阻断）/ 软约束（放行 + 提示）                      |
| 状态           | 在职 / 在途Offer / 在途待入职                       |
| **占编**       | 状态 ∈ {在职, 在途Offer, 在途待入职}                       |

**计数唯一口径**：所有人数统计必须复用 `calc.py` 的 `_COUNTED_STATUSES / rule_matches / _indicator_filter / _accounting_month / count_rule`，禁止另写一套计数逻辑。

## 3. 功能范围

| 模块       | 说明                                    |
| -------- | ------------------------------------- |
| 实时看板     | 每条规则按自身适用范围展示「年度 / 本月」的达成、在途、达成率 + 占比 |
| 规则配置     | 扁平列表增删改查、复制（未启用副本）、启停、Excel 导入/导出/模板  |
| 指标管理     | 维度 + 指标库的增删改查、Excel/CSV 导入/导出/模板      |
| 录入校验     | 模拟录入，三态判定（阻断 / 警告 / 通过），前置校验          |
| 人员数据     | 人员主数据 CRUD，**默认展示占编人员（在职+在途），可按状态筛选** |
| Offer 钩子 | 创建 Offer 时实时命中规则，硬约束阻断、软约束放行 + 提示     |

## 4. 关键业务规则

1. **扁平模型（v2.9）**：每条规则 = 独立的（适用范围 · 维度 · 指标 · 年度），`target` 恒为 1.0；已删除「占比 100% 加和校验」与「占比上下限」。
2. **人数目标承载于规则**：`annual_target`（年度）+ `monthly_targets`（12 月），月度之和必须等于年度。
3. **全局 / 指定范围互斥（非对称）**：同一（维度·年度）下不可同时存在全局与指定范围规则。保存指定范围 → 删除全局；保存全局且存在指定范围 → 拦截 400。
4. **唯一键含启用态**：启用原规则与未启用副本可共存；副本启用时撞启用键 → 409，占比超 100% → 400。
5. **录入校验三态**：实际 ≥ 目标 → 阻断；实际 < 目标 → 警告；否则 → 通过。`month_target == 0` 不参与判定；占比不参与校验。
6. **占编口径**：在职按「实际入职日期」、在途按「预计入职日期」计入对应核算月；日期缺失回退到 `month` 字段。

## 7. 非目标（明确不做的）

- 候选池不占编。
- 不引入「评分家族」评分体系。
- 无独立「人数规划表」（已删除，人数目标承载于规则）。
- 不做跨年度自动结转、不做人员批量在职/离职流转（当前仅手动维护 status）。
