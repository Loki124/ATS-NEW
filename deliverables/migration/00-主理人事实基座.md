## 四、用户与部门模型（需求 3/4/5 核心）

`apps/django/apps/core/models.py`：

- **`User(AbstractUser)`**（:39），表名保持 Django 默认 `auth_user`。
  - **`department`** FK → Department（:59，related_name='members'）
  - **`direct_manager`** FK → self（:66，related_name='subordinates'，**verbose_name='直接上级'**）← **需求 5 字段已存在**
  - `user_type`（INTERNAL/EXTERNAL，:105）、`uuid`（:114）、`deleted_at` 软删（:126）、`token_version`（:135）
  - `position_title` / `level` / `bu_president` / `solid_vp` / `dotted_vp`
  - Meta indexes：`(department, is_active)`、`(level)`
  - **`AUTH_USER_MODEL` 未设置**，迁移风险高，MUST NOT 重命名表
- **`Department`**（:180，db_table='departments'）
  - 树形：`parent` 自引用（:185）、`path`（:192）、`code` 自动生成 D+6 位（:249 `_next_department_code`）
  - 负责人：`leader`/`manager_2`/`manager_3`/`hrbp`（:195-222）
  - `is_active`、`sort_order`
  - `save()` 自动补 id（nanoid 21位）、code、path

## 五、数据字典（需求 6 落点）

`apps/django/apps/dictionary/`：

- **`DictionaryType`**（:18）：`code`(unique) / `name` / `english_name` / `description` / `dict_number`(自动 D+1) / `is_system` / `is_enabled`
- **`DictionaryItem`**（:60）：`type` FK / `parent` 自引用 / `key` / `value` / `english_name` / `description` / `sort_order` / `is_active` / `is_system`；unique_together(type,key)
- **注册机制**：`registry.py` 的 `register_dictionary_seed()` + `SEED_REGISTRY`；业务 app 在 `AppConfig.ready()` 注册，`post_migrate` 统一注入（`run_dictionary_seeds()`），种子期自动 `is_system=True`（`seed_context.set_seed_active`）。
- **样例**：`seeds.py` 中 `EDUCATION_ITEMS` 等为 `(key, 名称, 英文名, 排序)` 元组列表。
- 前端管理页：`pages/settings/DataDictionary.vue`。

> 结论：需求 6「直播间平台入字典」= 新增一个 DictionaryType + items，通过 seed 注册，**字典模块零改动**。
